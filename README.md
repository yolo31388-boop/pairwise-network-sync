# 网络同步与状态压缩系统

## 项目描述

网络同步与状态压缩系统的bug修复项目。核心模块 `network/network_sync.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 状态同步是全量同步无优先级无频率控制
- 增量压缩完全没做每次都发送完整状态
- 插值完全没做其他玩家移动是跳变的
- 丢包恢复完全没做丢包后状态不更新
- 带宽优化完全没做所有数据最高频率发送

## 运行测试

```bash
python -m pytest tests/test_network_sync.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
